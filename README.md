# rclone-vps-oauth

rclone-vps is a private OAuth client used by a single server to back up
its own files to the owner's Google Drive with rclone.

- Single user (the owner). No other users, no public service.
- The app only reads and writes the owner's own Google Drive.
- No data is collected, stored or shared with third parties.
